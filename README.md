# 📝 Todo List App

A simple and responsive Todo List application built using HTML, CSS, and JavaScript. This project allows users to add and delete tasks dynamically while practicing core JavaScript concepts like DOM manipulation and event handling.

## 🚀 Live Demo

🔗  https://rohanraut16.github.io/ToDo-List/

## ✨ Features

* Add new tasks
* Delete existing tasks
* Dynamic task rendering
* Instant UI updates
* Responsive design

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)

## 📚 Concepts Used

* DOM Manipulation
* Event Listeners
* Array Methods (`unshift`, `filter`)
* Dynamic Element Creation
* Functions and Objects
